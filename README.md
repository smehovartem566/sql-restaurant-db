# 🍽️ База данных «Ресторан»

Проектирование и разработка реляционной базы данных для автоматизации работы ресторана.  
**Курсовая работа** по дисциплине «Основы проектирования баз данных».

---

## 📌 О проекте

База данных охватывает ключевые процессы ресторана:

- Бронирование столиков
- Приём и обработка заказов
- Распределение блюд между поварами
- Автоматическое формирование чеков
- Финансовая аналитика и расчёт зарплат

**СУБД:** Microsoft SQL Server  
**Инструменты:** T-SQL, SSMS

## 🚀 Быстрый старт

1. Установите **Microsoft SQL Server** и **SSMS**.
2. Откройте [`FullTableCreateInsertTr.sql`](./FullTableCreateInsertTr.sql) и выполните.
3. База данных `restaurant` будет создана и заполнена тестовыми данными.
4. Готово. Можно выполнять запросы из папок `запросы для расчетов/` и `запросы/`.

> ⚠️ Скрипт [`FullTableCreateInsertTr.sql`](./FullTableCreateInsertTr.sql) предназначен для однократного выполнения. Повторный запуск создаст дублирующиеся данные.

---

## 📁 Содержимое репозитория

- **`FullTableCreateInsertTr.sql`** — главный скрипт (создание таблиц, триггеров, заполнение данными).
- **`create.sql`**, **`триггеры/`**, **`заполнение/`** — то же самое, разбитое на отдельные файлы.
- **`запросы для расчетов/`** — аналитические отчёты (меню, чек, загрузка залов, выручка, зарплаты).
- **`запросы/`** — оперативные изменения (изменить цену блюда, оплатить все чеки).
